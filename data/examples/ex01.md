## 이번에 하는 것
- CubeMX로 프로젝트 만들고 CubeIDE로 굽기
- 보드의 초록 LED(LD2)를 0.5초마다 깜빡이기
- 디버거로 코드를 한 줄씩 멈춰 보기

## 준비물
- NUCLEO-G474RE 1개, USB 케이블 (데이터 되는 것)
- [STM32CubeMX · CubeIDE 설치](../../setup/stm32cube/)를 마친 PC

## 1. 프로젝트 만들기 (CubeMX)
1. **File → New Project → Board Selector**에서 `NUCLEO-G474RE`를 고르고 Start Project.
2. "모든 주변장치를 기본값으로 초기화할까요?"에 **Yes**. LED · 버튼 · 가상 COM 포트가 미리 잡혀요.
3. **Project Manager** 탭에서
    - Project Name: `ex01-blink`
    - Toolchain / IDE: **STM32CubeIDE**
4. 오른쪽 위 **Generate Code**.

## 2. 코드 한 줄 넣기 (CubeIDE)
1. CubeIDE에서 **File → Import → Existing Projects into Workspace**로 방금 만든 폴더를 열어요.
2. `Core/Src/main.c`의 `while (1)` 안, `/* USER CODE BEGIN 3 */` 아래에 넣어요.

```c
HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
HAL_Delay(500);
```

`USER CODE BEGIN` / `END` 사이에 써야 CubeMX로 다시 생성해도 지워지지 않아요.

## 3. 굽고 확인하기
1. 보드를 USB로 연결해요.
2. 망치 아이콘(Build) → 벌레 아이콘(**Debug As → STM32 C/C++ Application**).
3. 디버거가 `main()` 첫 줄에서 멈추면 **Resume(F8)**. LD2가 깜빡이면 성공이에요.
4. `HAL_GPIO_TogglePin` 줄 왼쪽을 더블클릭해서 중단점을 걸어 보세요. 깜빡임이 멈추고, F8을 누를 때마다 한 번씩 바뀌어요.

## 해 보기
- 파란 버튼(B1)을 누르는 동안 빨리 깜빡이게 바꿔 보세요. `HAL_GPIO_ReadPin(B1_GPIO_Port, B1_Pin)`을 써요.
- 버튼을 눌렀을 때 값이 0인지 1인지는 **디버거에서 직접 확인**해 보세요. 보드마다 달라요.

## 막히면
- **보드가 안 잡혀요** → 충전 전용 케이블인지 확인. 장치 관리자에 "STLink"가 보여야 해요.
- **ST-LINK 펌웨어 업데이트하라고 나와요** → 안내대로 업데이트하고 USB를 다시 꽂아요.
