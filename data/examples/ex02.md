## 이번에 하는 것
- `printf`가 USB 케이블 하나로 PC 터미널에 찍히게 하기
- PC에서 친 글자를 보드가 그대로 돌려보내기(에코)

로그를 보는 길이 하나 생기면 이후 모든 회차에서 디버깅이 쉬워져요.

## 준비물
- 예제 01을 마친 NUCLEO-G474RE
- 터미널 프로그램: Tera Term (PuTTY도 괜찮아요)

## 1. UART 확인 (CubeMX)
1. 예제 01과 같은 방법으로 새 프로젝트 `ex02-uart-printf`를 만들어요. (Board Selector → 기본값 Yes)
2. **Connectivity → LPUART1**이 켜져 있는지 봐요. 이 보드는 LPUART1(PA2 · PA3)이 ST-LINK의 가상 COM 포트로 이어져 있어요.
3. 속도는 **115200 / 8비트 / 패리티 없음 / 정지 1비트**로 맞춰요.
4. Generate Code.

## 2. printf 연결 (main.c)
`/* USER CODE BEGIN Includes */` 아래:

```c
#include <stdio.h>
```

`/* USER CODE BEGIN 0 */` 아래:

```c
int __io_putchar(int ch)
{
  HAL_UART_Transmit(&hlpuart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
  return ch;
}
```

CubeIDE가 만든 `syscalls.c`가 `printf` → `_write` → `__io_putchar` 순서로 불러요. 그래서 이 함수 하나만 만들면 돼요.

`while (1)` 안 `/* USER CODE BEGIN 3 */` 아래:

```c
uint8_t c;
if (HAL_UART_Receive(&hlpuart1, &c, 1, 1000) == HAL_OK) {
  printf("받음: %c\r\n", c);
} else {
  printf("tick %lu\r\n", HAL_GetTick());
}
```

## 3. PC에서 보기
1. 장치 관리자 → 포트에서 **STMicroelectronics STLink Virtual COM Port (COMx)** 번호를 확인해요.
2. Tera Term → **Serial**, 그 COM 번호 → **Setup → Serial port**에서 115200.
3. 1초마다 `tick ...`이 찍히고, 키를 누르면 `받음: a`처럼 돌아오면 성공이에요.

## 해 보기
- `printf("%.2f", 3.14f)`를 찍어 보세요. 아무것도 안 나오면 **Project Properties → C/C++ Build → Settings → MCU Settings → Use float with printf**를 켜요.
- 한 글자씩 받는 대신, 엔터가 올 때까지 모았다가 한 줄로 처리하게 바꿔 보세요. 프로젝트 회차의 명령 콘솔이 이렇게 시작해요.

## 막히면
- **글자가 깨져요** → PC와 보드의 속도(115200)가 같은지 확인.
- **아무것도 안 나와요** → 다른 프로그램(CubeIDE 콘솔 등)이 COM 포트를 잡고 있지 않은지 확인하고 Tera Term을 다시 열어요.
- **줄이 계단처럼 밀려요** → 문자열 끝에 `\r\n`을 써요.
